# IPT Structural Design Patterns
# Running the Structural Design Patterns Labs

## Individual Labs

```bash
# Lab 1: Adapter Pattern
php lab1_adapter/with_pattern.php

# Lab 2: Bridge Pattern
php lab2_bridge/with_pattern.php

# Lab 3: Composite Pattern
php lab3_composite/with_pattern.php

# Lab 4: Decorator Pattern
php lab4_decorator/with_pattern.php
```

## Run All Labs

```bash
# Sequential (Windows PowerShell)
php lab1_adapter/with_pattern.php; php lab2_bridge/with_pattern.php; php lab3_composite/with_pattern.php; php lab4_decorator/with_pattern.php
```

## Without Pattern Versions (for comparison)

```bash
php lab1_adapter/without_web.php
php lab2_bridge/without_web.php
php lab3_composite/without_web.php
php lab4_decorator/without_web.php
```
